# Imagens das aeronaves

Coloque aqui um PNG por modelo, com o nome `<id do modelo>.png`. Se o arquivo
existir, ele aparece no card do Mercado no lugar da silhueta.

IDs atuais (veja `src/data/aircraft.ts`):

|----|--------|
| `atr72` | ATR 72-600 |

| `a220` | Airbus A220-300 |
| `b738` | Boeing 737-800 |
| `b737max8` | Boeing 737 MAX 8 |
| `a320` | Airbus A320neo |
| `a321neo` | Airbus A321neo |
| `b763er` | Boeing 767-300ER |

| `b789` | Boeing 787-9 |
| `a359` | Airbus A350-900 |
| `b77w` | Boeing 777-300ER |
| `a388` | Airbus A380-800 |

Formato sugerido: PNG com fundo transparente, proporção larga (~1000×420),
vista lateral ou de cima. Use imagens que você tenha direito de publicar
(o site é público) — por exemplo do Wikimedia Commons com a licença compatível.
